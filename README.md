A program that paints one delicious food picture: a tall stack of golden pancakes drowned in glossy maple syrup, a pat of butter melting on top, fresh blueberries and a strawberry, on a ceramic plate in warm morning light, steam still rising. One ingredient leads the whole picture — maple syrup: the glossy cap, the ribbons running down the stack, and the pool glistening on the plate.

Everything is drawn procedurally with Pillow and numpy — no network, no external assets, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The image is a 1024×1024 PNG, 301,738 bytes, within the 1 MiB and 1024×1024 gate. Both runs write identical bytes.
